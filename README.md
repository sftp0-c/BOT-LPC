# College MAX Bot

Проект бота колледжа для платформы MAX.

## Возможности
- регистрация студента: ФИО и группа;
- расписание по группе через PDF-ссылку;
- обратная связь с выбором сотрудника;
- заказ справки;
- обращения со статусами;
- скрытая панель superadmin;
- управление сотрудниками и правами рассылки;
- рассылка студентам;
- SQLite и Docker-персистентность;
- кнопки MAX.

## Настройка
Создайте `.env` на основе `.env.example` и укажите токен MAX и ID superadmin. Токен не добавляйте в Git.

## Docker
`docker compose up -d --build`

Проверка: `/health`.
